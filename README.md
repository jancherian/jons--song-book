# Jon's Song Book (Nashville Number System)

A chord chart app designed for musicians using the Nashville Number System, with inline lyrics support and a stage performance mode.

## ✨ Features
- **Nashville Number System**: Full scale degree charting (1–7, accidentals `b`/`#`, qualities `m`/`dim`, extensions `M7`/`m7`/`sus2`/`sus4`, and slash chords `/`).
- **Inline Lyrics**: Write and edit lyrics directly aligned under each chord bar.
- **Stage Performance Mode**: Dark high-contrast stage view, font scaling, auto-scroll, and instant key transposition between Nashville numbers and letter chords.
- **Stitch Design**: Luminous Harmonic theme with beveled glass panels, warm gold accents, and custom typography (`Hanken Grotesk` + `JetBrains Mono`).

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
